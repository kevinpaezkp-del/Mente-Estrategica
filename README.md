# Mente Estratégica · Laboratorios de datos

Sitio práctico para estudiantes del curso Mente Estratégica de LaCardio. El sitio contiene materiales para practicar SharePoint, Microsoft Lists, Excel, Power Automate y Slackbot.

El archivo `Solicitudes_Traslado_28_Registros.xlsx` contiene **una sola hoja** (`02_PEGAR_28`) y 28 registros de práctica. El laboratorio consiste en crear otros 4 registros manualmente y completar los 32 de la demostración.

Los cuatro prompts del curso cubren: dashboard HTML desde Excel, crear una lista en Slack, generar un tablero interactivo desde la lista y consultar pendientes/editar una solicitud.

## Publicación

Página prevista: https://kevinpaezkp-del.github.io/Mente-Estrategica/

En GitHub, activa **Settings → Pages → Deploy from a branch → main → /(root)** si todavía no está activado. El repositorio contiene un `index.html` estático, sin necesidad de servicios adicionales.

Los registros son ficticios; no se incluyen datos de pacientes.
